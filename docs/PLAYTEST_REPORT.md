# Playtest Report

## 记录规则

每一轮从空 IndexedDB 开始，由一名真人独立完成主线。记录墙钟时间，不记录自动化测试耗时；暂停、重试和加载等待应在备注中说明。三轮结束后再计算章节中位数和总时长。

记录工具：`pnpm playtest:timer -- --round <轮次> --player <化名> --device <设备> --browser <版本>`。主线模式记录 8 章；Optional 模式使用 `--mode postgame` 记录 5 个通关后环节。工具只保存真人按键确认的墙钟区间。

## 自动回归（不作为真人时长）

`pnpm report:progression` 使用固定种子、四种构筑和自动战斗样本，验证资源断点、战斗量与胜率趋势。它的“估算战斗分钟”只用于平衡回归，不能填入上表，也不能替代人工黄金路径。

已知自动回归结果：四种构筑均通过固定种子样本，8 个章节未发现超阈值资源断点；完整输出以命令结果为准。

真人记录完成后，将每轮的日期、设备、浏览器版本、章节时间、失败/重试次数和总时长填入上表，并重新执行 `pnpm lint`、`pnpm content:validate`、`pnpm test`、`pnpm test:e2e`、`pnpm build` 和 `pnpm assets:audit`。
