## 本轮完成的闭环

### 运行时与存档

- RootGameStore 直接持有并保存 V2 运行时状态；存档不再经过 V1/M1 转换、兼容导出或迁移注册表。
- V2 档案持久化章节任务、探索、采集、对白效果、门派、通关后循环和完整游戏运行时。
- 设置面板提供三个手动档；自动档在对白与战斗中途不会覆盖，损坏档、临时恢复、导入导出和配额异常均有覆盖。

### 八章主线与通关后循环

- 第 2–8 章的任务、热点、采集与对白由同一章节运行时消费，不再以聚合按钮跳过章节进度。
- 每章均有两类普通敌人、Boss、失败重试、自动档与桌面/手机章节 E2E。
- 结局后可继续原档，在门派页选择普通、精英或传说难度，生成、完成并领取委托；状态随 V2 档案恢复。

### 界面与资源

- 对话、章节对白和设置/图鉴面板由根状态互斥控制，避免同一时刻出现两个关闭按钮；旁白提示不拦截点击。
- 手机端江湖页改为单列流式布局，工具栏为五个 44px 触控入口，场景、旁白、行动区和底部导航不再重叠或裁切。
- 资源生命周期测试覆盖区域反复进入、离开与切换释放；性能 E2E 断言首屏不会请求未解锁章节的大图。
